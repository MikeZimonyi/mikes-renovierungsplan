# Mikes Renovierungsplan

Eine kleine, statische und mobilfreundliche Website für den Renovierungszeitplan.

## Veröffentlichen mit GitHub Pages

1. Repository auf GitHub öffnen.
2. **Settings → Pages** auswählen.
3. Unter **Build and deployment** als Source **Deploy from a branch** wählen.
4. Branch **main**, Ordner **/(root)** auswählen und speichern.
5. Nach dem Deployment ist die Seite unter `https://mikezimonyi.github.io/mikes-renovierungsplan/` erreichbar. GitHub zeigt die genaue URL auch unter **Settings → Pages**.

## Zeitplan aktualisieren

Die Texte und Termine stehen direkt in `index.html`. Änderungen dort speichern und committen. Die Website wird automatisch neu veröffentlicht.

Die Illustrationen liegen im Ordner `images/`. Die Website lädt außerdem die Schriftarten Nunito und Patrick Hand von Google Fonts; ohne Internetverbindung werden lokale Standardschriftarten verwendet.
